# Installer Documentation Index

This directory documents installation and first-deployment workflows for Wicofe OS.

## Scope
- Installation environment and user workflow.
- Disk/partition selection and destructive-operation confirmation.
- Bootloader installation and boot-entry configuration.
- Base-system deployment, initial configuration, logs, and failure handling.

## Ownership
[Wicofe-Image](https://github.com/Waizusora/Wicofe-Image) produces system images. [Wicofe-Storage](https://github.com/Waizusora/Wicofe-Storage) provides storage utilities. [Wicofe-Update](https://github.com/Waizusora/Wicofe-Update) manages in-place updates. [Wicofe-Recovery](https://github.com/Waizusora/Wicofe-Recovery) owns recovery workflows.

## Safety
Never format or repartition implicitly. Show the exact target, proposed layout, and data-loss consequences before execution. Define interruption and rollback behavior.
